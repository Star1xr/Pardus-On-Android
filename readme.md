# Pardus on Android - Auto Installation Script 🚀

An easy, automated way to install Pardus Linux on Android using Termux and proot-distro. This script handles the setup, user creation, and downloads the necessary startup files automatically.

## 🇬🇧 English: How to Install
**Requirements:** Ensure you have the latest [Termux](https://github.com/termux/termux-app/releases) and [Termux-X11](https://github.com/termux/termux-x11/releases) installed.

1. Open Termux and download the automated script:
   ```bash
   wget https://raw.githubusercontent.com/Star1xr/Pardus-On-Android/main/install_en.sh
2. Make it executable:
   ```bash
   chmod +x install_en.sh
3. Run the script and follow the on-screen instructions (It will ask for a username, password, and desktop environment choice):
   ```bash
   ./install_en.sh
4. Once finished, start your desktop environment using the script provided at the end of the installation (e.g., ./startxfce_pardus.sh).
